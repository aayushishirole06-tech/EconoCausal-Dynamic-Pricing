# EconoCausal - Dynamic Pricing using Causal Machine Learning

## 📌 Overview

EconoCausal is an AI-powered dynamic pricing system that estimates the causal impact of discounts on customer purchasing behavior. Instead of predicting who will buy, it predicts who is likely to buy **because of a discount**, helping businesses optimize promotional strategies.
